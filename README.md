
# Impact of Medication for Lifestyle Diseases on Hospital Readmission

## 📌 Project Overview
This project analyzes the impact of medications and clinical factors on hospital readmission rates for patients with lifestyle diseases. The goal is to identify key drivers of readmission and build predictive models to support healthcare decision-making.

## 🧪 Key Steps
- Cleaned and validated healthcare data by handling missing and invalid values
- Performed race-wise imputation for medical specialty using Chi-square dependency testing
- Engineered diagnosis features by grouping ICD codes into clinical categories
- Applied encoding and feature scaling while preserving missing-value semantics
- Built and evaluated machine learning models to predict readmission risk

## 📊 Models Used
- Logistic Regression
- Gradient Boosting / XGBoost / LightGBM (experimentation)

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Seaborn, Matplotlib
- XGBoost, LightGBM

## 📈 Outcome
The project demonstrates how data-driven approaches can help identify patients at higher risk of readmission and support preventive healthcare strategies.
